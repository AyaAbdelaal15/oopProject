# 🎮 GameOOP

A responsive **Game Discovery Website** built with **HTML, CSS, and JavaScript**, using a games API to fetch and display free-to-play games dynamically.

The project provides a modern interface where users can browse games, filter them by category, and view detailed information about each game.

## 🔌 API

The project uses the **Free-To-Play Games Database API** to retrieve game information dynamically.

The API provides data such as:

* Game title
* Game thumbnail
* Game description
* Genre
* Platform
* Publisher
* Developer
* Release date
* Game URL
